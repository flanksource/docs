# <Icon name="ldap" /> LDAP

<!-- Source: modules/canary-checker/api/v1/checks.go#LDAPCheck -->

The LDAP check:

* Binds to an LDAP or LDAPS server using the configured username and password.
* Searches from the configured base DN.
