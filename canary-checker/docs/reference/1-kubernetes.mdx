# <Icon name="k8s" /> Kubernetes

<!-- Source: modules/canary-checker/api/v1/checks.go#KubernetesCheck -->

The Kubernetes check queries Kubernetes resources such as Pods and evaluates their health or readiness.

## Healthy

Using `healthy: true` is functionally equivalent to this CEL expression:

```cel
dyn(results).all(x, k8s.isHealthy(x))
```

The following example uses `healthy: true`.

```yaml title="kubernetes-healthy.yaml" file=<rootDir>/modules/canary-checker/fixtures/k8s/kubernetes-minimal_pass.yaml
```

See the CEL function <CommonLink to="cel" anchor="k8sishealthy">k8s.isHealthy</CommonLink> for more details

## Ready

Similar to the `healthy` flag, the `ready` flag is functionally equivalent to this CEL expression:

```cel
dyn(results).all(x, k8s.isReady(x))
```

### Remote clusters

A single canary-checker instance can connect to any number of remote clusters via custom kubeconfig.
Either the kubeconfig itself or the path to the kubeconfig can be provided.
