### Webhook

The webhook receiver accepts every field of an [HTTPConnection](/docs/guide/playbooks/actions/http#http) — `url`, `connection`, `username`, `password`, `bearer`, `oauth`, `headers`, `tls` and `awsSigV4` — plus:

<Fields rows={[
  {
    field: "method",
    description: "HTTP method to use. Defaults to `POST`",
    scheme: "string"
  }
]}/>

### Fallback

<Fields rows={[
  {
    field: "delay",
    description: "Wait this long before treating the primary send as a failure",
    scheme: "duration"
  }
]}/>

Along with `delay`, a fallback takes any one of the `to.*` recipient fields — `person`, `team`, `email`, `connection`, `url`, `properties`, `playbook` or `webhook`.
