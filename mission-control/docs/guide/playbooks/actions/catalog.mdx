# <Icon name="config-db"/> Catalog Action

Catalog action creates a config item in the [catalog](/docs/guide/config-db). Use it to record the output of a playbook — an audit, a report, a review — as a first class config item that can be searched, related to other resources and notified on.

The config item is attached to an existing [scraper](/docs/guide/config-db/scrapers), so it participates in that scraper's retention and change tracking.

```yaml title="record-security-audit.yaml"
apiVersion: mission-control.flanksource.com/v1
kind: Playbook
metadata:
  name: record-security-audit
spec:
  description: Record the result of a security audit in the catalog
  configs:
    - types: [Kubernetes::Cluster]
  actions:
    - name: audit
      exec:
        script: ./audit.sh $(.config.name)
    - name: Save audit
      catalog:
        name: 'Security audit — {{.config.name}}'
        scraper: mission-control/audits
        type: 'SecurityAudit::Report'
        config_class: Report
        config: '{{ getAction "audit" | .result.stdout }}'
        health: healthy
        tags:
          cluster: '{{.config.name}}'
```
