# <Icon name="http"/> HTTP

<!-- Source: modules/config-db/api/v1/http.go#HTTP -->

The HTTP scraper allows you to collect data from HTTP endpoints and APIs. It supports various authentication methods and data transformation capabilities.


| Field       | Description                                                                  | Scheme                                             | Required |
| ----------- | ---------------------------------------------------------------------------- | -------------------------------------------------- | -------- |
| `schedule`  | Specify the interval to scrape in cron format. Defaults to every 15 minutes. | [Cron](/docs/reference/types#cron)                      |          |
| `retention` | Settings for retaining changes, analysis and scraped items                   | [`Retention`](/docs/guide/config-db/concepts/retention) |          |
| `http`      | Specifies the list of HTTP configurations to scrape.                         | [`[]HTTP`](#http-configuration)                    |          |
| `logLevel`  | Specify the level of logging.                                                      | `string`                                     |          |
| `full`      | Set to `true` to extract [changes](/docs/guide/config-db/concepts/changes#extracting-changes) and [access logs](/docs/guide/audit/access-logs) from scraped configurations. Defaults to `false`. | `bool`                                       |          |

## Pagination

Paginated APIs are followed by evaluating a CEL expression against each response to find the next page.

| Field          | Description                                                                                                                                                            | Scheme   | Required |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------- | -------- |
| `nextPageExpr` | CEL expression that extracts the next page from the response. It receives a `response` map with `body`, `headers`, `status` and `url`, and returns either a string (the next URL), a map (a request spec with `url`, `method`, `body`, `headers`) or `null` to stop | `string` | `true` |
| `reduceExpr`   | CEL expression that merges pages using an accumulator. It receives `acc` (a list, initially empty) and `page` (the response body), and returns the new accumulator     | `string` |          |
| `perPage`      | Process each page independently instead of merging them                                                                                                                | `bool`   |          |
| `maxPages`     | Maximum number of pages to fetch. `0` means unlimited                                                                                                                  | `int`    |          |
| `delay`        | Delay between page requests e.g. `500ms`, `2s`                                                                                                                         | `string` |          |

```yaml title="http-pagination.yaml"
http:
  - url: https://api.example.com/v1/items?page=1
    type: Example::Item
    id: $.id
    name: $.name
    pagination:
      nextPageExpr: 'response.body.next_url != null ? response.body.next_url : null'
      reduceExpr: 'acc + page.items'
      maxPages: 20
      delay: 500ms
```
