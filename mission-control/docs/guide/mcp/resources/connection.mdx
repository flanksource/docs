# Connection Resource

Identify a connection by its namespace and name.

## URI Template

`connection://{namespace}/{name}`

**MIME Type:** `application/json`

## Description

This resource returns a connection's ID, name, namespace, type, and source. It doesn't return the connection's settings or credentials.

The caller needs `read` on connections.

## Example Usage

### Sample Request

**URI:** `connection://production/aws-prod`

### Sample Response

```json
{
  "id": "0193b2c4-2a6f-7d8e-9b1a-4c5d6e7f8a9c",
  "name": "aws-prod",
  "namespace": "production",
  "type": "aws",
  "source": "UI"
}
```

## Use Cases

- **Discovery**: Confirm that a connection exists before referencing it in a playbook or health check
- **Configuration Auditing**: List which types of connections are configured and where they came from
