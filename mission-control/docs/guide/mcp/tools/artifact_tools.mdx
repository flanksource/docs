# Artifact Tools

Tools for reading the [artifacts](/docs/installation/artifacts) that playbook runs and health checks produce.

## read_artifact_metadata

Get an artifact's metadata by ID — filename, size, content type, path, the check or playbook run it belongs to, and its timestamps.

<Fields rows={[
  {field: "id", scheme: "string", description: "UUID of the artifact", required: true}
]} />

## read_artifact_content

Read the content of an artifact file.

<Fields rows={[
  {field: "id", scheme: "string", description: "UUID of the artifact", required: true},
  {field: "max_length", scheme: "number", description: "Maximum number of bytes to read. Defaults to 1048576 (1 MB). The tool truncates larger artifacts and adds a note"}
]} />

### Example Usage

**Prompt:** "What was in the log file that run produced?"

**Result:** Returns the artifact's content. The tool truncates the content when it exceeds `max_length`.
